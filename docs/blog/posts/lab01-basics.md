# Lab 1：变量、字符与简单循环

本次实验练习变量的定义与赋值、格式化输入输出、字符比较和大小写转换，并用循环完成简单累加。

<!-- more -->

## 1. 基本数据类型变量的赋值与输出

### 题意

分别定义 `int`、`float` 和 `char` 类型的局部变量，在赋值前后按指定标签和格式输出。字符变量赋值后，还要分别按字符形式和整数值输出。

### 思路

严格按题目给出的顺序书写七条输出语句。前三条输出直接读取尚未赋值的局部变量，之后的输出必须在对应变量赋值后进行。`float` 使用 `%f`，字符分别使用 `%c` 和 `%d`。

### 参考代码

```c
#include <stdio.h>

int main(void) {
    int a;
    float b;
    char c;

    printf("[INT_BEFORE]%d[/INT_BEFORE]\n", a);
    a = 0;
    printf("[INT_AFTER]%d[/INT_AFTER]\n", a);

    printf("[FLOAT_BEFORE]%f[/FLOAT_BEFORE]\n", b);
    b = 0.0f;
    printf("[FLOAT_AFTER]%f[/FLOAT_AFTER]\n", b);

    printf("[CHAR_BEFORE]%c[/CHAR_BEFORE]\n", c);
    c = 'a';
    printf("[CHAR_AFTER_C]%c[/CHAR_AFTER_C]\n", c);
    printf("[CHAR_AFTER_D]%d[/CHAR_AFTER_D]\n", c);

    return 0;
}
```

### 点评与易错点

- **首次输出没有标准答案。** 未赋值的局部变量具有不确定值，读取它还会产生未定义行为。结果可能随编译器、优化选项和运行环境改变，不能根据一次运行推断其固定值。
- 不要为了得到样例中的首次输出而提前给变量赋值，也不要手动打印一个猜测的值。
- 字符 `'a'` 用 `%c` 输出时显示为 `a`，用 `%d` 输出时显示其字符编码；在本实验环境中是 `97`。
- 标签、方括号、斜杠和换行都属于输出格式的一部分，必须原样书写。编译器针对未初始化变量给出警告，正是本题希望观察的现象。

## 2. 输出字母表中靠前的字母

### 题意

输入两个大小写相同的英文字母，输出字母表中靠前的字母；两个字母相同时输出该字母。

### 思路

在本实验使用的字符编码中，同一组大写或小写字母按字母表顺序连续编码，因此可以直接比较两个 `char` 变量的值。`a < b` 时输出 `a`，否则输出 `b`，其中也包含了二者相等的情况。

### 参考代码

```c
#include <stdio.h>

int main(void) {
    char a, b;

    scanf(" %c %c", &a, &b);

    if (a < b) {
        printf("%c\n", a);
    } else {
        printf("%c\n", b);
    }

    return 0;
}
```

### 点评与易错点

- `%c` 前的空格用于跳过输入中的空白字符，使程序能正确处理空格分隔或换行分隔的字母。
- 不需要把字符显式转换成整数，关系运算符可以直接比较两个字符。
- 不需要单独为两个字母相等增加分支，`else` 已经正确处理这种情况。
- 字母表顺序的比较依赖题目所用的常见字符编码，不宜把这一结论推广到任意字符集。

## 3. 小写字母转换为大写字母

### 题意

输入一个小写英文字母，输出对应的大写字母。

### 思路

利用同一字母大小写形式之间的固定编码差值，将 `ch` 相对于 `'a'` 的偏移量加到 `'A'` 上。例如，`'g' - 'a'` 得到字母表中的相对位置，再加上 `'A'` 就得到 `'G'`。

### 参考代码

```c
#include <stdio.h>

int main(void) {
    char ch;

    scanf(" %c", &ch);
    ch = ch - 'a' + 'A';
    printf("%c\n", ch);

    return 0;
}
```

### 点评与易错点

- 表达式 `ch - 'a' + 'A'` 比直接写 `ch - 32` 更清楚，也不依赖某个具体的差值数字。
- 字符常量应写为 `'a'` 和 `'A'`；双引号表示字符串，不适用于这里的字符运算。
- 输入已经保证是小写英文字母，因此无须增加范围判断。

## 4. 选做：计算 1 到 10 的累加和

### 题意

计算并输出整数 `1 + 2 + ... + 10`，没有输入。

### 思路

用 `sum` 保存累加结果，并初始化为 `0`。循环变量 `i` 从 `1` 变化到 `10`，每次执行 `sum += i`，最终输出 `sum`。

### 参考代码

```c
#include <stdio.h>

int main(void) {
    int i;
    int sum = 0;

    for (i = 1; i <= 10; i++) {
        sum += i;
    }

    printf("%d\n", sum);

    return 0;
}
```

### 点评与易错点

- `sum` 必须先初始化为 `0`，否则累加会从不确定的值开始。
- 循环条件 `i <= 10` 包含终值 `10`；写成 `i < 10` 会漏掉最后一项。
- `sum += i` 等价于 `sum = sum + i`，是累加计算的常用写法。
