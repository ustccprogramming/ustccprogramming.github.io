# Lab 3：表达式求值与整数判断

本次实验分为两部分。第一部分练习关系、逻辑、赋值、条件和算术表达式的求值，理解类型转换与短路求值；第二部分用整数除法计算数字位数，并用分支判断数值范围和整除关系。

## 第一部分：表达式求值

### 1. 关系和逻辑表达式

#### 题意

依次读入四组整数，计算前四个表达式；第五个表达式不需要输入。按题目顺序输出五行整数，每行末尾换行。

#### 思路

关系运算和逻辑运算的结果都是 `int` 类型：假为 `0`，真为 `1`。逻辑运算把 `0` 看作假，把任意非零值看作真。先确定运算符的优先级，再判断是否发生短路求值。

代入题目给出的变量值，可以得到：

| 小问 | 表达式 | 计算过程 | 结果 |
| --- | --- | --- | --- |
| (1) | `b > c && b == c` | `3 > 4` 为假，右侧不再求值 | `0` |
| (2) | `!(a > b) && !c || 1` | `!0 && !4 || 1`，即 `1 && 0 || 1` | `1` |
| (3) | `!(x = a) && (y = b) && 0` | 先把 `2` 赋给 `x`，`!2` 为假，后续不再求值 | `0` |
| (4) | `!(a + b) + c - 1 && b + c / 2` | 左侧为 `0 + 4 - 1 = 3`，右侧为 `3 + 2 = 5`，二者均非零 | `1` |
| (5) | `1 && 30 % 10 >= 0 && 30 % 10 <= 3` | `30 % 10` 为 `0`，两个范围判断均为真 | `1` |

#### 参考代码

```c
#include <stdio.h>

int main(void) {
    int a, b, c;
    int x, y;

    scanf("%d %d", &b, &c);
    printf("%d\n", b > c && b == c);

    scanf("%d %d %d", &a, &b, &c);
    printf("%d\n", (!(a > b) && !c) || 1);

    scanf("%d %d", &a, &b);
    printf("%d\n", !(x = a) && (y = b) && 0);

    scanf("%d %d %d", &a, &b, &c);
    printf("%d\n", (!(a + b) + c - 1) && (b + c / 2));

    printf("%d\n", 1 && 30 % 10 >= 0 && 30 % 10 <= 3);

    return 0;
}
```

#### 点评与易错点

- `&&` 的优先级高于 `||`，所以第 (2) 问先计算逻辑与，再计算逻辑或。代码中的括号只是把这种分组写清楚。
- `&&` 左侧为假时不再计算右侧，`||` 左侧为真时不再计算右侧。第 (3) 问的样例中，`x` 被赋值为 `2`，但 `y = b` 不执行，不能在表达式之后直接读取尚未赋值的 `y`。
- `=` 是赋值，`==` 才是比较是否相等。赋值表达式也有值，例如 `(x = a)` 的值是赋给 `x` 的值。
- 第 (4) 问的 `!` 只作用于 `(a + b)`。逻辑与的结果是 `1`，不会返回操作数 `3` 或 `5`。
- 题目要求计算原表达式，因此即使某些表达式的结果恒为 `0` 或 `1`，也应保留表达式，不直接打印常量答案。

### 2. P62 赋值和条件表达式

#### 题意

在同一个程序中，用六个语句块分别读入各小问的变量，计算并打印赋值或条件表达式的值。每个语句块独立使用自己的变量，避免上一问的赋值影响下一问。

#### 思路

复合赋值会更新左侧变量；赋值表达式的值是赋值后左侧变量的值。逗号运算符按从左到右的顺序求值，整个逗号表达式取最后一项的值。条件表达式根据条件真假选择 `?` 后或 `:` 后的值。

代入题目给出的变量值，可以得到：

| 小问 | 表达式 | 计算过程 | 结果 |
| --- | --- | --- | --- |
| (1) | `a += a + b` | `a = 2 + (2 + 3)` | `7` |
| (2) | `a *= b % c` | `a = 2 * (3 % 4)` | `6` |
| (3) | `a /= c - a` | `a = 2 / (4 - 2)` | `1` |
| (4) | `a += a -= a *= a` | 同一完整表达式中对 `a` 的修改与读取缺少必要的先后顺序 | 未定义，样例给出 `0` |
| (5) | `a = (a = ++b, a + 5, a / 5)` | `b` 先变为 `4`，`a` 变为 `4`；`a + 5` 不修改 `a`；最后取 `4 / 5` | `0` |
| (6) | `(a >= b >= 2) ? 1 : 0` | 按 `((a >= b) >= 2)` 计算，即 `(0 >= 2)` | `0` |

**第 (4) 问没有由标准 C 保证的固定输出。** 下方保留题目原式，供编译、观察和对比；即使某次运行输出 `0`，也不能据此认定原式的标准结果是 `0`。

#### 参考代码

```c
#include <stdio.h>

int main(void) {
    {
        int a, b;

        scanf("%d %d", &a, &b);
        printf("%d\n", (a += a + b));
    }

    {
        int a, b, c;

        scanf("%d %d %d", &a, &b, &c);
        printf("%d\n", (a *= b % c));
    }

    {
        int a, c;

        scanf("%d %d", &a, &c);
        printf("%d\n", (a /= c - a));
    }

    {
        int a;

        scanf("%d", &a);
        /* 原式有未定义行为，不能保证输出为 0。 */
        printf("%d\n", (a += a -= a *= a));
    }

    {
        int a, b;

        scanf("%d %d", &a, &b);
        printf("%d\n", (a = (a = ++b, a + 5, a / 5)));
    }

    {
        int a, b;

        scanf("%d %d", &a, &b);
        printf("%d\n", ((a >= b) >= 2) ? 1 : 0);
    }

    return 0;
}
```

#### 点评与易错点

- 赋值运算符从右向左结合，但**结合方向不等于求值顺序**。第 (4) 问虽然可以分组为 `a += (a -= (a *= a))`，却不能因此断言外层读取 `a` 一定发生在内层修改之后。依据 [C11 草案 N1570 的 6.5 第 2 段及 6.5.16.2](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)，原式属于未定义行为；增加括号也不能消除这个问题。
- 如果希望明确表达“先平方，再减去自身，最后加上自身”的过程，可将第 (4) 问改成下面三条语句。样例中 `a` 依次变为 `4`、`0`、`0`。这是明确指定计算顺序的改写，不是原式在标准 C 下的等价变形。

    ```c
    a *= a;
    a -= a;
    a += a;
    printf("%d\n", a);
    ```

- 第 (5) 问的 `a + 5` 只计算数值，不进行赋值，因此不会把 `a` 变成 `9`。最后一项 `a / 5` 为整数除法，`4 / 5` 得到 `0`，再由最外层赋值写回 `a`。
- 第 (6) 问不能按数学中的连续不等式理解。`a >= b` 只会得到 `0` 或 `1`，这两个值都不大于等于 `2`，因此条件恒为假。若要表示两个条件同时成立，应使用 `&&` 连接，但本题必须按原式求值。
- 第 (2) 问要求 `c` 非零，第 (3) 问要求 `c - a` 非零；题目给出的数值满足这些要求。
- 六组输入之间的空格或换行都可以被 `scanf` 正常处理，但输出必须按题目要求分成六行。

### 3. P62 算术表达式

#### 题意

`a`、`b` 为 `int` 类型，`x`、`y` 为 `double` 类型。第一问不需要输入，后三问分别读入各自的变量。输出四行：第二问输出整数，其余三问输出保留两位小数的浮点数。

#### 思路

先判断每一步运算的操作数类型。两个整数相除时进行整数除法，结果向零截断；之后再与浮点数相加，也不会补回已经丢失的小数部分。后缀 `a++` 在表达式中使用自增前的值，强制类型转换则只作用于紧随其后的操作数。

代入题目给出的变量值，可以得到：

| 小问 | 表达式 | 计算过程 | 输出 |
| --- | --- | --- | --- |
| (1) | `3.5 + 1 / 2 + 56 % 10` | `1 / 2` 为 `0`，`56 % 10` 为 `6` | `9.50` |
| (2) | `a++ * 1 / 3` | 使用自增前的 `3`，计算 `3 * 1 / 3`；本语句结束后 `a` 为 `4` | `1` |
| (3) | `x + a % 3 * (int)(x + y) % 2 / 4` | `a % 3` 为 `0`，整数部分为 `0`，结果为 `x` | `3.50` |
| (4) | `(float)(a + b) / 2 + (int)x % (int)y` | `5.0 / 2 + 3 % 4`，即 `2.5 + 3` | `5.50` |

#### 参考代码

```c
#include <stdio.h>

int main(void) {
    int a, b;
    double x, y;

    printf("%.2f\n", 3.5 + 1 / 2 + 56 % 10);

    scanf("%d", &a);
    printf("%d\n", a++ * 1 / 3);

    scanf("%d %lf %lf", &a, &x, &y);
    printf("%.2f\n", x + a % 3 * (int)(x + y) % 2 / 4);

    scanf("%d %d %lf %lf", &a, &b, &x, &y);
    printf("%.2f\n", (float)(a + b) / 2 + (int)x % (int)y);

    return 0;
}
```

#### 点评与易错点

- 第 (1) 问中，`3.5` 不会让另一个子表达式 `1 / 2` 自动变成浮点除法。要得到 `0.5`，应写 `1.0 / 2`，但本题不能修改原式。
- 第 (2) 问的 `a++` 与 `++a` 不同。将其写成 `++a` 会改变表达式所用的值；即使样例中两种写法恰好都输出 `1`，也不代表它们等价。
- `*`、`/`、`%` 的优先级相同，从左向右结合。第 (3) 问应按这个顺序确定整数部分的分组。
- `(int)(x + y)` 是先求和再转成整数；`(int)x % (int)y` 是分别转换后再求余。浮点数转为整数时舍去小数部分，不是四舍五入；求余的除数 `(int)y` 必须非零。
- `(float)(a + b) / 2` 在除法前完成类型转换，因此得到浮点商；如果改成 `(float)((a + b) / 2)`，整数除法丢失的小数部分无法恢复。
- 读入 `double` 使用 `scanf` 的 `%lf`，打印浮点结果使用 `printf` 的 `%.2f`。后三问都重新读入所需变量，不沿用上一问修改后的值。

## 第二部分：整数处理与分支判断

### 1. 整数数字位数

#### 题意

读入一个 `long` 类型的整数 `n`，满足 `-65535 <= n <= 65535`，输出它的十进制数字位数。负号不计入位数，`0` 的位数为 `1`。

#### 思路

先把负数变成正数，再反复将 `n` 除以 `10`。每执行一次整数除法，就去掉末尾一位，直到结果变成 `0`。用 `do ... while` 让计数过程至少执行一次，输入为 `0` 时也能得到 `1`。

例如，`-65535` 先变为 `65535`，之后依次变为 `6553`、`655`、`65`、`6`、`0`，共执行五次，因此输出 `5`。

#### 参考代码

```c
#include <stdio.h>

int main(void) {
    long n;
    int count = 0;

    scanf("%ld", &n);

    if (n < 0) {
        n = -n;
    }

    do {
        count++;
        n /= 10;
    } while (n != 0);

    printf("%d\n", count);

    return 0;
}
```

#### 点评与易错点

- 题目要求按 16 位系统考虑，不能用可能只有 16 位的 `int` 保存 `65535`。输入变量使用 `long`，对应的输入格式为 `%ld`。
- 输入范围已保证为 `-65535` 到 `65535`，在 `long` 范围内取相反数是安全的。位数最多为 `5`，计数变量使用 `int` 即可。
- 如果只写 `while (n != 0)`，输入 `0` 时循环不会执行，容易错误地输出 `0`。`do ... while` 让这一情况也计数一次。
- 负号不属于数字位，不能把负数的位数额外加一。每次执行的是整数除法，不需要转成浮点数或字符串。

### 2. 整除验证

#### 题意

读入一个整数 `n`。如果不在闭区间 `[-1000000, 1000000]` 内，输出 `Error`；在范围内且同时被 `3` 和 `5` 整除时输出 `Yes`，其余情况输出 `No`。输出单独一行，末尾换行。

#### 思路

先判断是否超出范围，只有范围合法时才判断整除关系。区间外对应 `n < -1000000 || n > 1000000`；同时整除对应 `n % 3 == 0 && n % 5 == 0`。

使用一组 `if ... else if ... else`，保证每次运行只输出一种结果。为兼容前一题提到的 16 位系统，仍使用 `long` 保存输入。

#### 参考代码

```c
#include <stdio.h>

int main(void) {
    long n;

    scanf("%ld", &n);

    if (n < -1000000L || n > 1000000L) {
        printf("Error\n");
    } else if (n % 3 == 0 && n % 5 == 0) {
        printf("Yes\n");
    } else {
        printf("No\n");
    }

    return 0;
}
```

#### 点评与易错点

- 两个端点都属于合法范围，应使用 `<` 和 `>` 判断越界，不能使用 `<=` 或 `>=`。
- 超出范围的两个条件用 `||` 连接；同时被 `3` 和 `5` 整除的两个条件用 `&&` 连接。也可以用 `n % 15 == 0` 判断同时整除。
- `0` 能同时被 `3` 和 `5` 整除，因此应输出 `Yes`。负的整数倍同样满足要求，例如 `-15` 也输出 `Yes`。
- 必须先检查范围。例如 `1000005` 虽然能被 `3` 和 `5` 整除，仍应输出 `Error`。
- 按输入输出要求，程序只打印 `Error`、`Yes` 或 `No`，不额外打印输入提示；注意大小写和行末换行。
