# CS1003.05 计算机程序设计

中国科学技术大学 CS1003.05 的课程主页，用 [Zensical](https://zensical.org/) 生成，通过 GitHub Pages 发布参考答案。

站点地址：<https://ustccprogramming.github.io/>

## 本地预览

```sh
pip install -r requirements.txt
zensical serve
```

打开 <http://127.0.0.1:8000/>。

## 发布答案

在 `docs/blog/posts/` 新增一篇 Markdown，将 `categories` 设为 `实验` 或 `作业`，文章会进入对应栏目。确认可以公开后推送到 `main`。具体步骤见 [发布答案](docs/guide/publish.md)。

不要把学生名单、成绩或作业原文放进本仓库。
